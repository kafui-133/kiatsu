# kiatsu
気圧変化による頭痛見える化

## 気圧ずつう予報

気圧の変化（直近3時間・6時間）から頭痛の注意度を出すスマホ向けWebアプリです。

- 公開URL: https://kafui-133.github.io/kiatsu/
- スマホのブラウザで開いて「ホーム画面に追加」するとアプリのように使えます（オフライン時は前回のデータを表示）。

### 公開設定（GitHub Pages）

Settings → Pages → Build and deployment で Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save。
